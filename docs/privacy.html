시행일 2026-11-20

1. 수집하는 정보

  • Riot 로그인(RSO) 시: Riot ID(게임 이름#태그), PUUID, Riot이 발급한 액세스·리프레시 토큰
  • Riot API로 조회한 경기 정보: 챔피언, 킬/데스/어시스트, 승패, 경기 시각

이메일, 비밀번호, 결제 정보는 수집하지 않습니다. 비밀번호는 Riot이 직접 처리하며 본 서비스에 전달되지 않습니다.

2. 이용 목적

그룹 멤버의 내전 전적·승률 통계를 만들어 그룹에 보여주는 데에만 사용합니다. 광고·판매·제3자 제공은 하지 않습니다.

3. 공개 범위

통계에는 로그인해 공유에 동의한 멤버만 이름이 표시됩니다. 동의하지 않은 플레이어는 이름 없이 표시됩니다.

4. 보관 및 삭제

토큰은 접근이 제한된 저장소에 보관합니다. 동의 철회 또는 삭제 요청 시 토큰과 해당 플레이어의 통계를 지체 없이 삭제합니다. Riot 계정 설정에서 앱 연결을 해제해도 토큰은 더 이상 사용할 수 없습니다.
